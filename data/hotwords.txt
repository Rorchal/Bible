# 热词表 —— 修正语音识别的固定错字
#
# 两种规则：
#
#   正确词 = 错写1, 错写2      【确定性替换】直接改掉。
#                              用于错写本身不是正常词的情况（尽钱、零界）。
#
#   正确词 ? 易混词            【交给模型判断】不直接改，只提示模型按上下文抉择。
#                              用于易混词本身是常用词的情况（一人、二人）——
#                              盲替换会毁掉「因一人的悖逆」这类经文。
#
# 两种都能跟 ! 例外列表：
#   = 规则的例外会被护住，不参与替换；
#   ? 规则的例外作为反例进提示词，告诉模型这些说法本身是对的。
#
# 以 # 开头的是注释，空行忽略。
#
# 这些替换是**确定性**的：整理前先把原文里的错写换成正确词，
# 模型输出后再兜一遍。每次运行会报告每个词命中了多少次，
# 你可以据此判断某条规则是不是加错了。
#
# ⚠️ 中文没有词边界，替换是直接的子串替换。
# 加新词前想一下：这个错写会不会是某个正常词的一部分？
# 比如把「胜利」当成「圣灵」的错写就很危险，「胜利」本身是常用词。

敬虔 = 尽钱, 近钱
灵界 = 零界
义人 = 艺人 ! 手艺人, 工艺人, 演艺人员, 文艺人

# ── 交给模型按上下文判断的易混词 ───────────────────────────
# 「一人」「二人」本身都是极常用的词，而且正好出现在核心经文里：
#   罗马书 5:19「因一人的悖逆……因一人的顺从」
#   创世记 2:24「二人成为一体」
#   阿摩司书 3:3「二人若不同心，岂能同行」
# 所以只能让模型看上下文决定，不能盲替换。

义人 ? 一人 ! 因一人的悖逆, 因一人犯罪, 因一人的顺从, 一人之下
恶人 ? 二人 ! 二人成为一体, 二人同心, 夫妻二人, 他们二人, 二人一同
