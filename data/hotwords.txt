# 热词表 —— 修正语音识别的固定错字
#
# 格式：  正确词 = 错写1, 错写2, ...
# 以 # 开头的是注释，空行忽略。
#
# 这些替换是**确定性**的：整理前先把原文里的错写换成正确词，
# 模型输出后再兜一遍。每次运行会报告每个词命中了多少次，
# 你可以据此判断某条规则是不是加错了。
#
# ⚠️ 中文没有词边界，替换是直接的子串替换。
# 加新词前想一下：这个错写会不会是某个正常词的一部分？
# 比如把「胜利」当成「圣灵」的错写就很危险，「胜利」本身是常用词。
