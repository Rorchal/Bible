# 把原始转录文本放在这里

一段录音一个文件。支持三种格式，脚本会自动识别：

| 后缀 | 说明 |
|---|---|
| `.txt` | 纯文本。ASR 直出的无标点长文也可以，正是第二步要处理的。 |
| `.srt` | 字幕格式，带时间轴。**推荐** —— 时间戳会被保留进每一段，将来检索时能定位到录音的第几分钟。 |
| `.vtt` | WebVTT，同上。 |

## 文件命名

文件名会成为这篇讲道的 ID，建议用有意义的名字：

```
data/01_raw/
├── 2024-03-创世记-亚伯拉罕的信心.srt
├── 2024-04-罗马书第八章.txt
└── ...
```

不要用空格，用连字符。

## 然后运行

```bash
python -m pipeline.refine
```
